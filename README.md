# Muscles à angles — atlas 3D des faisceaux

Atlas interactif : squelette articulé en 3D, faisceaux musculaires animés pendant l'exercice, longueur de chaque faisceau en direct sur la courbe tension-longueur, chapitre biomécanique et QCM.

Page unique (`index.html`), sans build. Three.js est chargé depuis jsDelivr.

Modèle pédagogique : points d'attache anatomiques, longueurs indicatives.
